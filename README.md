# TONO ROOTS KUDO

遠野ROOTS工藤のブランドサイトです。カッパ漬けをはじめとした遠野の漬物と、旬の野菜を紹介しています。

## プレビュー

```sh
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開きます。

## GitHub Pages

リポジトリの **Settings → Pages** で **Deploy from a branch** を選び、**main / (root)** を指定すると配信できます。サイトはリポジトリ名を含むURLでも表示できます。

掲載写真はサイト掲載用です。写真の再利用には権利者の許諾が必要です。
